## Descrição do Projeto

A **Pokédex** é uma aplicação web interativa que permite aos usuários explorar informações sobre Pokémons, como nomes, números, imagens e estatísticas. A aplicação utiliza dados da API [PokéAPI](https://pokeapi.co/), oferecendo uma experiência divertida e educativa para os fãs de Pokémon.

Os usuários podem:

* Pesquisar Pokémons por nome ou número.
* Navegar entre os Pokémons usando botões de "próximo" e "anterior".
* Visualizar imagens animadas e dados adicionais sobre os Pokémons.

---

## Funcionalidades

1. **Busca por Nome ou ID:**

   * Permite digitar o nome ou o número do Pokémon na barra de busca para exibir informações específicas.

2. **Navegação Sequencial:**

   * Botões "Anterior" e "Próximo" permitem navegar por Pokémons em ordem numérica.

3. **Exibição de Informações:**

   * Nome do Pokémon.
   * Número do Pokémon.
   * Imagem animada (ou estática) do Pokémon.

4. **Interface Responsiva:**

   * Design responsivo que funciona em dispositivos móveis e desktops.

5. **Fallback para Erros:**

   * Exibe mensagens amigáveis para entradas inválidas ou quando o Pokémon não é encontrado.
